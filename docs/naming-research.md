# Naming Research: Domain and Trademark Knockout Screen

**Project:** Industrial coatings company website (provisional brand "Vantrex Coatings") · **Date:** 2026-10-09 (Rounds 2–4 same day); decision and §5 added 2026-10-12 · **Prepared for:** Lucas Fairfield

## 0. What this is and is not

This is a **knockout screen**, not legal clearance. It answers two questions for each candidate: is the `.com` domain registered, and does an exact or near-exact mark already appear in US federal trademark records? It does **not** replace a professional clearance search by a trademark attorney, which also covers phonetic and visual similarity across all relevant classes, state registrations, common-law (unregistered) use, and foreign registers (Canada, EU, WIPO) if the company will sell outside the US. Nothing here is legal advice.

**Relevant trademark classes for an industrial coatings company:** Class 2 (paints, varnishes, lacquers, anti-corrosion preparations), Class 1 (industrial chemicals, resins, adhesives — adjacent and often cited in confusion analyses), Class 40 (coating/treatment services, if the company applies coatings), Class 35/42 if services are offered.

## 1. Method and sources

| Check | Source | How |
|---|---|---|
| `.com` / `.net` registration | Verisign registry RDAP (`rdap.verisign.com`), the authoritative registry database | Queried live from Lucas's machine via the built-in browser, 2026-10-09 19:51–19:59 UTC. `404` = not registered; a record = registered (registration date and status captured). |
| US federal trademark records (exact and prefix) | Justia Trademarks (public mirror of USPTO application/registration data) | Searched each candidate and key root/prefix variants. Validated the tool first with a known mark (URAGUARD → returned Sheboygan Paint Company's 2021 and 2026 filings). |
| Unregistered / common-law use | Web search | Searched each finalist for existing companies or products. |
| Parked-domain status | HTTP redirect check | For vantrex.com only. |

Limitations: Justia reflects USPTO data with some lag and does not show live/dead status in search results; prefix matching is approximate; no phonetic search was run; no state, Canadian, EU or WIPO registers were checked; social-media handle availability was not checked. All of these are in the next-steps list.

## 4. Recommendation (as of 2026-10-09 — superseded by the decision in §5)

1. **Retire "Vantrex" as the working name.** Replace the placeholder in `content/site.config.ts` when a decision is made; nothing else in the architecture depends on the name.
2. **Owner preference is for simple names (Round 2).** Shortlist for attorney clearance, in order: **Steelbend Coatings, Hammerforge Coatings, Ironbend Coatings**, with Ironpoint and Weldpoint as reserves. All have zero records in Classes 1 and 2, no coatings or chemicals businesses found using them, and the `[name]coatings.com` domain free. Steelbend is the strongest combination: two ordinary words, zero trademark records in any class, and the only other user of the word is a guesthouse business.
3. **Round-1 coined finalists (Tegmar, Scutrel, Acieris, Chalybex)** remain in the file as a fallback if counsel knocks out the simple names; they are more distinctive legally but the owner found them unappealing.
4. **Owner's stated taste (Round 4): short, hard-consonant, product-brand names.** Shortlist for attorney clearance: **Girder Coatings** (real word, 0 Class 2 records, domain free), **Rokton** and **Kordax** (coined, zero USPTO records, domains free), with **Bollard** and **Gantry** as real-word reserves. These supersede the Round 2 compounds if the owner confirms the sound is right.
5. **Regional option (Round 3).** If the owner wants a Fairfield/Solano identity, **Suisun Coatings** and **Carquinez Coatings** are the cleanest (zero Class 1/2 records, no businesses found, domains free). **Fairfield Coatings** is viable as a surname brand with fairfieldcoatings.com free, but has a 2025 Class 1 adhesives filing (FAIRFIELD F F) nearby and is inherently a weak mark. The local story can also be told through the address and copy under a Round 2 name.
6. **Do not register domains or file applications yet** (operating rule 15). Availability changes daily; be ready to register `[name]coatings.com` (plus `.net`, and the bare `.com` if purchasable and wanted) the same day counsel gives a preliminary go-ahead.
