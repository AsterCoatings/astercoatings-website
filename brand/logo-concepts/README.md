# Aster logo concepts — 2026-10-16

Four directions (A Star, B Plate, C Coat line, D Nut), each as horizontal and stacked lockups and as the mark alone, on light and on dark. All text is converted to outlines (Michroma for the wordmark, Barlow for the descriptor), so the SVGs need no fonts installed.

Colours: ink #14181F, accent #C84A18, white. No gradients or effects, so every file reproduces in one colour and in print.

`make_logos.py` regenerates every file from the site's font files; when Mirano is licensed, point `textpaths.py` at the Mirano woff2 and rerun to get the wordmark in the final face. Once a direction is chosen it should be refined by hand (optical spacing, a proper favicon set, PNG exports) before use.
